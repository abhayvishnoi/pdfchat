# DoChat (PDF Chat)

DoChat is split into three applications:

- [Angular user interface](./UI/README.md)
- `BE/` — Node.js/Express API.
- `pypdfservice/` — Python PDF processing service.

Install and run each service from its own directory. The UI README documents
its Angular setup and links to the backend and Python-service configuration.
Configure database and AI-service credentials locally; do not commit secrets.
