# DoChat by AV Projects

### Requirements

Angular: ^18.2.11.
Node:^18.19.1

##### Replace Gemini Api Key under (src/environments) in environment.development.ts and environment.ts

`apiKey: 'YOUR_API_KEY'`

### Install Modules

`npm i`

### To Run Development server execute below command

`npm start`

### To build the project

Run `ng build` . The build artifacts will be stored in the `dist/` directory.

### To run node server

replace you mongo connection string in .env

npm i
node server.js

### To run python server

pip install -r requirements.txt
python app.py
